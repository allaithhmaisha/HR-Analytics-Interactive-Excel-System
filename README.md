# Interactive HR Analytics Excel System 📊👥

## 📌 Project Overview
This project goes beyond standard visualization to deliver a comprehensive, multi-tab executive HR system built in **Microsoft Excel**. Managing **11,992 total employee records**, the system utilizes advanced data modeling and an interactive corporate interface to uncover the core drivers behind employee turnover, satisfaction trends, and department-level behaviors.

---

## 🛠️ System Architecture & Methodology

### 1. Data Cleaning & Structural Preprocessing 🧹
* Cleaned and filtered extensive employee dataset columns for high consistency.
* Evaluated and verified key performance fields including employee evaluation scores, project counts, and monthly working hours.

### 2. Multi-Tab Dynamic UI/UX Design 🎨
Designed a fully synchronized corporate interface split into three primary tabs for seamless exploration:
* **Dashboard Tab:** Displays top-level corporate KPIs, satisfaction distribution, and a complete salary structure—fully controlled by interactive **Slicers** (Region, Department, Salary).
* **Summary Tab:** Provides deep analytical matrix correlations between promotions, work accidents, and attrition rates (`Left Work`) broken down by department.
* **Contact Hub Tab:** Formatted a customized business communication index to streamline operational workflows across units.

## 💡 Key Business Takeaways
* **Retention Alert:** Deep analysis on the *Summary* sheet isolates specific departments experiencing critical attrition rates (`Left Work`) exceeding standard thresholds.
* **Burnout Correlation:** Cross-referencing satisfaction levels with project loads and average monthly hours successfully detects operational burnout trends.
* **Salary Impact:** Clear visual breakdown showing higher turnover frequencies concentrated within lower-tier salary brackets.
